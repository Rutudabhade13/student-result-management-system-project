Student Result Management System

📌 Project Overview

The Student Result Management System is a web-based application developed as a BCA college assignment. It helps administrators or teachers manage student records and calculate academic results efficiently.

🎯 Features

- Add student records
- Edit student details
- Update subject marks
- Delete student records
- Store marks for multiple subjects
- Calculate total marks
- Calculate percentage
- Generate grades
- Display Pass / Fail status
- View student result details
- Simple and user-friendly interface

📚 Subjects

The system supports multiple subjects, including:

- Python
- Java
- Operating System
- DBMS
- Computer Networks

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python / Flask
- Database: SQLite
- Development Platform: Replit
- Version Control: GitHub

⚙️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Install the required dependencies.
4. Run the Flask application.
5. Open the provided local URL in your browser.

📊 Result Calculation

The system automatically calculates:

Total Marks
"Total = Sum of all subject marks"

Percentage
"Percentage = (Total Marks / Maximum Marks) × 100"

The grade and Pass/Fail status are generated based on the calculated percentage.
